\## Three Git Commands I Learned



1\. `git add .` — Stages changes for a commit.

2\. `git commit -m "message"` — Saves staged changes in Git history.

3\. `git push` — Uploads local commits to a remote repository.



\## Purpose of GitHub



GitHub hosts Git repositories online, allowing developers to store code, track changes, and collaborate on projects.



\## One Benefit of Branches



Branches allow developers to work on new features separately without directly changing the main branch.
